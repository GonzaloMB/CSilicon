# CSilicon
Run, benchmark and optimize Counter-Strike 2 on Apple Silicon.

> [!IMPORTANT]
> CSilicon is currently in the research and architecture phase. It does not yet
> install or launch Counter-Strike 2.

The project is being designed as a local-first, reproducible compatibility and
diagnostics toolkit for macOS. Start with the [documentation map](docs/README.md)
and the [current project status](docs/STATUS.md).
